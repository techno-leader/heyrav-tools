What this is. case-viewryt.html now carries a specific set of conventions. None of them have been rolled out to the rest of the live cluster. Each item below is one convention: why it changed, a live before/after mini-render, the CSS diff, and a decision per page. Nothing is edited by this document — it produces the brief, the refactor is a separate job.
  • Every “now:” value was read out of the source file, not estimated.
  • Rows marked not present on this page are excluded from the count.
  • Items tagged proposed are not done on case-viewryt.html either — they are house rules, so adopting one means fixing ViewRyt too.
  • Decisions are saved to localStorage on every click. Closing the tab is safe.
