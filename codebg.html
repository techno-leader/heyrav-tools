D-CODE · rain · glyph sets

Letters, numbers, symbols — three cases

Same ingredients in all three: English letters, digits and operators. The only variable is the case the letters are drawn in, which at 13px is what decides whether the columns break up or stay rigid.

Two rules apply to all three: a glyph is never repeated directly below itself, and never sits directly below its neighbour in the source string, so no pair can read as a run. Churn re-rolls a fifth of the field on each of the four glitch beats, so a falling column is a scramble rather than a fixed string sliding by.
