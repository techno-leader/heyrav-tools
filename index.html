How the instruments are made

From James McDonald's Dive Club session on building with Claude (Oct 2026), and from reading how accessgrid.com's own motion is built.

Build a tool, not eight mockups

A throwaway tool you can play with finds the idea faster than a page of variations.

Always a random button

Random across every parameter turns up results nobody would aim for. Undo keeps it safe.

One line of help per control

Each slider says what it does, so the tool is its own documentation.

One easing, almost everywhere

Ease-out quint, cubic-bezier(.23,1,.32,1), at 200 to 500ms. Most of "smooth" is never mixing curves.

Write the motion as numbers

Every timing named and commented - stagger, snap, sweep - so it can be tuned, not storyboarded.

Self-plagiarise

A shelved idea is a library entry. This page exists so none of them are lost.
